# Atlassian API token expiry (search-verified)

- API token expiration can be set from 1 day up to 1 year at creation.
- After December 15, 2024: new API tokens default to expiring in one year.
- After March 13, 2025: tokens created before December 15, 2024 were also set to expire in one year.
- Service-account API tokens: expiration between 1 and 365 days.
